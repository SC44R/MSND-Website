# A Midsummer Night's Dream Eng114 Sec:1 Drama Showcase site

## Files
- `index.html` home page with schedule and countdown
- `play.html` story page
- `gallery.html` rehearsals gallery page
- `game.html` mini game page
- `ticket.html` Get Ticket page
- `style.css` moonlit-forest / fairy theme
- `script.js` countdown, game logic, and ambient audio toggle
- `assets/` put your images/audio here (create this folder if it's not there)

## Before you go live, fill in these 4 things

1. **University logo**
   Save your logo as `assets/university-logo.png`. It's already wired into the header.

2. **Rehearsal photos**
   Drop photos into `assets/` named `rehearsal-1.jpg` through `rehearsal-6.jpg`
   (or edit the `<img>` tags in the Gallery section of `gallery.html` to match your
   actual filenames/count, add or remove `<div class="gallery-item">` blocks freely).
   No captions are added, per your request, just the photos.

3. **Forest ambience audio**
   Download a royalty-free track from Pixabay, search "forest night ambience",
   "magical fairy forest", or "enchanted forest ambient", and save it as
   `assets/forest-ambience.mp3`. The "Play Forest Sounds" button on Home is
   already connected to this file.

4. **Get Ticket link**
   In `ticket.html`, find:
   ```html
   href="PASTE_YOUR_GOOGLE_DRIVE_LINK_HERE"
   ```
   then replace it with your real Drive link (E-Ticket + E-Playbill).

## Hosting
Any static host works (GitHub Pages, Vercel, Netlify, your university's own
hosting). Just upload the whole folder as-is.
